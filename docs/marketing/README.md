# Marketing Materials Boundary

This directory contains non-engineering communications material retained for history and content work.

Marketing copy is **not** release evidence. Claims about production readiness, wallet integration, deployment state, feature counts, security, users, revenue, or external providers must be verified against current code, CI, deployment evidence, and release documentation before publication.

The repository root is reserved for engineering-facing material such as source, architecture, build/test configuration, security documentation, and release evidence.
